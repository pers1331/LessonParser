## Практическая работа 4

В программу была добавлена поддержка выполнения команд из файла.

### Реализованные функции

* Добавление занятий через команду `ADD`
* Удаление занятий через команду `REM`
* Сохранение данных через команду `SAVE`
* Выполнение файла команд с автоматическим обновлением интерфейса
* Загрузка данных из текстового файла
* Добавление и удаление занятий через графический интерфейс
* Обработка ошибок с использованием исключений
* Запись ошибок в файл `errors.log`
* Модульное тестирование основных компонентов программы
